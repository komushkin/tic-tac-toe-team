## Описание проекта

Игра «Крестики-нолики» для двух игроков за одним компьютером.
Игроки по очереди ставят фигуры на поле 3 × 3. Программа определяет
победителя или ничью и считает результаты партий за текущий сеанс.

## Функциональные возможности

### Основные

- Ходы X и O с помощью мыши или клавиатуры.
- Проверка победы и ничьей.
- Анимация фигур и выделение выигрышной линии.

### Дополнительные

- Счёт побед и ничьих, новая партия и сброс счёта.
- Настройка скорости анимации и справка с правилами.

## Требования к системе

- Python 3.10 или выше.
- Windows, macOS или Linux с графическим интерфейсом.
- Стандартные библиотеки: tkinter и time. Сторонних пакетов нет.

## Установка и запуск

### 1. Скачать проект

```bash
git clone https://github.com/komushkin/tic-tac-toe-team.git
cd tic-tac-toe-team
```

### 2. Создать и активировать виртуальное окружение

Папка venv сохранена по требованиям работы. После скачивания пересоздайте
окружение для своего компьютера.

Windows (командная строка cmd):

```bat
python -m venv --clear --without-pip venv
venv\Scripts\activate.bat
```

macOS / Linux:

```bash
python3 -m venv --clear --without-pip venv
source venv/bin/activate
```

### 3. Проверить зависимости

Внешних пакетов нет, поэтому устанавливать их не нужно.
requirements.txt содержит это пояснение. Если tkinter отсутствует, в Windows
добавьте компонент Tcl/Tk через установщик Python, в Linux — пакет python3-tk.

### 4. Запустить игру

```bash
python main.py
```

### Управление

- Щелчок по свободной клетке или клавиши 1–9 — поставить фигуру.
  Клетки нумеруются по строкам слева направо, сверху вниз.
- R или «Новая партия» — очистить поле, сохранив счёт.
- «Сбросить счёт» — обнулить счёт и поле.
- Ползунок — изменить длительность анимации следующего хода.
- F1 или «Правила» — справка; Escape — выход.

## Структура проекта

```text
tic-tac-toe-team/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
└── venv/
```

main.py содержит всю программу: правила игры, отрисовку, управление и запуск.
Код разделён на классы, но оставлен в одном файле, так как проект небольшой.
requirements.txt описывает зависимости, venv содержит виртуальное окружение,
а .gitignore исключает временные файлы Python.

## Пример использования

Запустите main.py и по очереди нажмите 1, 4, 2, 5, 3, дожидаясь окончания
анимации каждого хода. X займёт верхнюю строку и победит.
Нажмите R, чтобы начать следующую партию.
